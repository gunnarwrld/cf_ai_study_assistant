## 🎯 Best Practices for Using the Study Assistant

### Effective Questions

✅ **Good**: "What's the difference between mitosis and meiosis?"

- **Search history**: Use the search feature to find specific topics
- **Continue learning**: "Can we go deeper into...?"
- **Review sessions**: "What did we discuss about...?"

## 💬 Pro Tips

1. **Be Specific**: The more detailed your question, the better the answer
2. **Ask Follow-ups**: Don't hesitate to dig deeper
3. **Request Examples**: Examples make concepts clearer
4. **Use Memory**: Reference previous conversations
5. **Search History**: Find topics you've discussed before
6. **Try Different Angles**: If you don't understand, ask for a different explanation
7. **Practice Active Learning**: Ask the AI to quiz you
8. **Build Knowledge**: Start simple and progressively add complexity
